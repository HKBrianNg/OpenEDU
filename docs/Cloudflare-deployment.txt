////////////////////////////////////
前端运行平台
////////////////////////////////////

1. 安装Wangler CLI
npm install -g wrangler

2. Cloudflare 部署

a.修改代码后​，启动本地测试
    cd c:/Projects/OpenEDU/client
    npm run dev

b.本地测试后, 构建安装包
    npm run build

c.构建成功后​，上传安装包到Cloudflare平台
    npx wrangler pages deploy dist --project-name=openedu-client

d.上传后等一两分钟​ → 刷新网站查看效果
https://d24e31c9.openedu-client.pages.dev

////////////////////////////////////
后端运行平台
////////////////////////////////////

# 安装
    cd c:/Projects/OpenEDU/server-ai
    pip install hypercorn

# 启动开发服务器（带热重载）
hypercorn main:app --reload --bind 127.0.0.1:8000

# 如果要用 WebSocket 或流式响应，加上 worker-class
hypercorn src.main:app --reload --bind 127.0.0.1:8000 --worker-class asyncio

测试游戏流程一般是：
http://127.0.0.1:8000
/api/health
/api/games/jungle/init
/api/games/jungle/move
/api/games/jungle/ai-move
/api/games/jungle/{game_id}
/api/games/jungle/{game_id}/replay
