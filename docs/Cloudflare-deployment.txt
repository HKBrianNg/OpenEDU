////////////////////////////////////
前端运行平台
////////////////////////////////////

1. 安装Wangler CLI
npm install -g wrangler

2. Cloudflare 部署

a.修改代码后​，启动本地测试
    cd c:/Projects/OpenEDU/client
    npm run dev

b.本地测试后, 构建安装包
    npm run build

c.构建成功后​，上传安装包到Cloudflare平台
    npx wrangler pages deploy dist --project-name=openedu-client

d.上传后等一两分钟​ → 刷新网站查看效果
https://d24e31c9.openedu-client.pages.dev

////////////////////////////////////
后端运行平台
////////////////////////////////////

a. 本地开发

1.安装
    cd c:/Projects/OpenEDU/server-ai
    pip install hypercorn

2. 激活虚拟环境
cd /c/Projects/OpenEDU/server-ai
source .venv/Scripts/activate

3. 启动 FastAPI 服务（热重载）
hypercorn src.main:app --reload --bind 127.0.0.1:8000 --worker-class asyncio

b. 本地 Docker 验证

# 构建镜像
cd /c/Projects/OpenEDU/server-ai
docker build -t server-ai:local .

# 运行容器
docker run --rm -p 8080:8080 server-ai:local

docker version
docker info
docker ps

# 停止所有运行中的容器
docker stop $(docker ps -q)

# 先退出 Docker Desktop
# 然后关闭 WSL
wsl --shutdown
